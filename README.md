## Hi, I'm Anthony Chavez 👋

**Senior Embedded Firmware Engineer** · Reno, NV · open to contract work and full-time roles

I build production firmware for connected devices, from bare-metal 8051 and ARM Cortex-M through embedded
Linux. My work runs end-to-end: bringing up sensors and peripherals from datasheets and schematics,
writing bootloaders and OTA field updates, and building fleet telemetry for devices in the field.
9+ years shipping hardware, with a BSEE from the University of Nevada, Reno.

### What I work on

- **Bare-metal & RTOS:** 8051 (Silicon Labs EFM8), STM32 / Cortex-M, NXP i.MX RT, ESP32 (ESP-IDF), FreeRTOS,
  low-power sleep/wake design
- **Embedded Linux:** Raspberry Pi / CM4 daemons, libgpiod, Bluetooth Classic & BLE, Wi-Fi, LTE/GNSS modems
- **Connectivity & fleet:** MQTT, device telemetry and cloud command dispatch, custom bootloaders, OTA updates
- **Buses & peripherals:** UART, I²C/SMBus, SPI, CAN, RS-485, USB, PWM, ADC/DAC, motor and battery charger ICs
- **Test & tooling:** pytest, Ceedling/Unity TDD, hardware-in-the-loop rigs, Python production and flashing
  tools, Renode/QEMU simulation, logic analyzers, oscilloscopes, JTAG/SWD

### Languages

C · C++ · Python · Rust · Assembly · C#
